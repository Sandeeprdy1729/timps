How it works

Every connector runs the same pipeline.

Connect once, and each connector stays quiet in the background — feeding facts into the same memory your agents already share.

01 · Connect

Authorize locally

One command opens a consent screen in your browser. Tokens land in ~/.timps/ — nothing leaves your machine.

02 · Sync & distill

Facts, not firehose

Each sync distills raw content into 1–3 knowledge facts. Raw copies stay local; only distilled facts enter memory.

03 · Remember

Recall from anywhere

Facts land in semantic memory with source tags — searchable with timps recall, the desktop app, or any MCP client.

Privacy by design

Read-only. Local-first. Yours.

🔒

Read-only scopes

Connectors never send, edit, or delete. No write permission is ever requested.

💾

Stored locally

Raw copies and tokens stay in ~/.timps/ with 600 permissions. Nothing is uploaded.

🧂

Distilled only

Only compact knowledge facts enter memory — never the raw stream.

🔌

Disconnect anytime

One command or button revokes access and deletes stored credentials.
